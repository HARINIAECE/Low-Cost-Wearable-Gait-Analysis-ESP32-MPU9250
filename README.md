Low-Cost Wearable Gait Analysis System Using ESP32 and MPU9250

Overview
A low-cost wireless wearable system designed to monitor lower-limb movements and estimate knee flexion angles during walking using IMU sensors and ESP32 microcontrollers.

Features
- Wearable thigh and shank movement monitoring.
- Wireless data transmission using ESP-NOW.
- Knee-angle estimation from segment orientations.
- Gait parameter extraction and visualization.
- Portable and low-cost hardware design.

Hardware
- ESP32 Development Boards (3)
- MPU9250 IMU Sensors (2)
- Rechargeable Batteries
- Breadboard and Jumper Wires

Software & Technologies
- Arduino IDE
- Embedded C/C++
- I²C Communication
- ESP-NOW Protocol
- Microsoft Excel

System Architecture
Thigh IMU + ESP32 and Shank IMU + ESP32 → ESP-NOW → Receiver ESP32 → Laptop → Gait Data Analysis.

Gait Parameters
- Maximum, minimum and average knee angle
- Knee Range of Motion (ROM)
- Cadence
- Step Time
- Stride Time

Applications
- Clinical Gait Assessment
- Rehabilitation Monitoring
- Sports Biomechanics
- Wearable Healthcare

Project Status
Hardware prototype developed with wireless data acquisition and initial gait parameter analysis demonstrated.
