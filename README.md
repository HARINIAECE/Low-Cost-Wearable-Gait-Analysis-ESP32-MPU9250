# Low-Cost-Wearable-Gait-Analysis-ESP32-MPU9250
A low-cost, wearable gait analysis system using **MPU9250 IMU sensors and ESP32**. Two IMU sensors monitor **thigh and shank movements** during walking. **ESP-NOW** enables wireless data transmission to a central ESP32 receiver. The system estimates knee angle and key gait parameters for real-time movement analysis.
